# 📊 Superstore Sales Dashboard | Power BI

A comprehensive Power BI dashboard built using the Superstore dataset to analyze sales performance, profitability, and regional business insights. The dashboard enables stakeholders to monitor key business metrics and make data-driven decisions through interactive visualizations.

---

## 📌 Project Overview

This dashboard provides an analytical view of Superstore sales data by highlighting:

- Sales performance across different cities and regions
- Profit analysis by state
- Sales distribution by payment mode
- Top-performing locations based on sales
- Interactive filtering and business insights

The project demonstrates Power BI data visualization, dashboard design, and business intelligence reporting.

---

## 🚀 Features

- 📈 Sales Analysis by Region
- 🏙️ Top Cities by Sales
- 💰 Profit Analysis by State
- 💳 Sales Distribution by Payment Mode
- 🎯 Interactive Dashboard
- 📊 Business KPI Visualization

---

## 📂 Dashboard Visualizations

| Visualization | Description |
|--------------|-------------|

| Column Chart | Regional Sales Comparison |

| Stacked Area Chart | Profit by State |
